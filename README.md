# Starlight Carnival

A character-driven pachinko puzzle game set in a travelling celestial carnival. Aim a pearl through the pegs, clear every orange sun and catch the moving basket to earn another shot.

**[Visit the carnival](https://nearbycoder.github.io/starlight-carnival/)** · **[Play Adventure](https://nearbycoder.github.io/starlight-carnival/play/index.html?mode=adventure)** · **[Open the game menu](https://nearbycoder.github.io/starlight-carnival/play/)**

## Inside the game

- Forty handcrafted missions across eight worlds. Each performer restores an attraction and brings a different power to the board.
- Adventure, Free Play, six-ball Score Attack and reproducible Seeded Challenge boards.
- Fixed-timestep ball physics, shot replays, original synthesised music and locally saved campaign records.
- Graphics quality, independent music and effects controls, reduced motion and high-contrast aiming.

## Controls

Move the mouse to aim and click to shoot. On a keyboard, use Left and Right to aim, hold Shift for precision and press Space to fire. On touchscreens, drag to aim and tap Fire. Escape pauses and R opens restart confirmation.

## Run locally

Open `index.html` for the illustrated website or `play/index.html` for the full-screen game. The game is a standalone HTML file with Canvas 2D artwork and Web Audio synthesis. Google Fonts are optional and the game uses system fonts when offline.

## GitHub Pages

Pages serves the root of the `main` branch. The landing page and its artwork live in `index.html` and `assets/`. The playable game lives in `play/index.html`. No build step or dependencies are required. Campaign progress is local to each browser and origin.
